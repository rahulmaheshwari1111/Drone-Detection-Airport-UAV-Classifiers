# Roadmap

## Phase 1
- Detection ingestion
- Naive track association
- Baseline SVM-compatible classification API
- PostgreSQL persistence

## Phase 2
- Kalman filter tracking
- Auto feature extraction from track windows
- Auto classification on track updates
- Threat score to alert pipeline

## Phase 3
- Redis live state
- Kafka or NATS streaming
- WebSocket live updates
- Operator dashboard

## Phase 4
- Model registry integration
- Drift detection
- Replay and incident workflows
- Stronger OOD handling
